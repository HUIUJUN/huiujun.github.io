1. 서비스와 기기에 저장하는 정보

BookShelf는 사용자가 이용 권한을 가진 EPUB·PDF·만화·이미지·텍스트를 읽고 정리하는 앱입니다. 별도의 BookShelf 회원 계정을 만들지 않으며, 책 콘텐츠를 제공하지 않습니다.

  • 도서 경로·제목·저자·태그·파일 식별 정보, 서재 분류, 표지·꾸미기 이미지, 즐겨찾기, 읽던 위치, 책갈피·메모·필기와 재단·보기 설정 등을 기기에 저장합니다. 이는 도서 열기·정리·이어보기·사용자 설정 유지에 사용됩니다.
  • 미리보기·추출한 페이지·OCR·번역 결과와 언어 모델 등의 캐시가 저장 공간을 사용할 수 있습니다. 재단·꾸미기는 원본을 덮어쓰지 않는 방식입니다. 변환·내보내기를 선택하면 새 파일을 별도로 저장합니다.
  • Android의 폴더 일괄 추가는 모든 파일 접근 권한을 사용하여 사용자가 선택한 폴더의 지원 도서를 찾고 원본 위치에서 읽습니다. 권한을 허용하지 않아도 시스템 파일 선택창으로 개별 파일을 추가할 수 있습니다. 파일 제공자에 따라 선택한 파일의 임시 사본이 만들어질 수 있습니다.
  • 파일 접근은 도서 가져오기·열기·검색 등에 사용하며, 도서 원문·페이지 이미지·책장 목록을 광고 요청에 넣지 않습니다.

2. OCR와 번역

온디바이스 처리: 지원되는 기기·언어의 OCR와 온디바이스 번역은 기기에서 입력과 출력을 처리합니다. 언어 모델 설치·갱신과 SDK 관리에 인터넷 연결이 필요할 수 있습니다. 이 온디바이스 입력·출력 원문과 이미지는 ML Kit 진단 전송에 포함되지 않습니다.

ML Kit 진단: Google ML Kit는 SDK 제공·개선·호환성 관리를 위해 기기·앱 정보, 설치 식별자, API 설정·사용량, 입력·출력 크기, 성능·오류·설정 언어 등의 정보를 Google에 보낼 수 있습니다. 이는 기기 내에서 처리한 책 원문·이미지를 전송하는 것과 다릅니다. 자세한 내용은 ML Kit 데이터 처리 안내와 ML Kit 약관·개인정보 안내를 참조하세요.

선택한 온라인 번역: 원문 전송 안내에 동의하고 온라인 번역을 사용하면 현재 쪽과 미리 번역할 주변 쪽의 텍스트 또는 OCR 인식 문장, 원문·번역 언어가 Google Translate로 전송됩니다. 응답 실패 시 MyMemory(Translated)에 전송될 수 있습니다. 번역 요청에 책 파일 전체나 페이지 이미지는 넣지 않습니다. 해당 제공자는 요청 내용과 IP 등 연결 정보를 받을 수 있으며, 수신한 정보에는 해당 제공자의 정책이 적용됩니다.

민감한 내용은 온라인으로 번역하지 마세요. 앱 설정에서 온라인 번역 원문 전송 허용을 끄면 이후 온라인 번역 요청을 차단할 수 있습니다. 이미 외부 제공자에게 전달된 요청을 회수하거나 해당 제공자의 보관본을 앱에서 삭제하는 것은 아닙니다.

3. 선택적 백업·동기화와 로그인

사용자가 동기화를 실행하면 책 식별 정보, 서재·꾸미기 설정과 이미지, 읽던 위치·책갈피·메모·필기·재단 정보 및 공통 설정 등을 선택한 Google Drive·지원 설정된 OneDrive·WebDAV/NAS 또는 연결한 다른 기기로 전송합니다. 데이터는 사용자가 선택한 저장소에 보관됩니다. 클라우드 동기화에는 책 원본을 올리지 않습니다. 기기 간 원본 파일 전송은 파일을 별도로 선택했을 때 실행됩니다.

Google Drive는 앱 전용 데이터 영역을, OneDrive는 지원되는 앱 전용 폴더를 사용합니다. Google·Microsoft 계정 연결은 해당 제공자의 승인 화면을 사용합니다. Google API에서 받은 데이터는 사용자가 요청한 백업·복원·동기화에 사용하며 광고 타겟팅이나 데이터 판매에 사용하지 않습니다.

로그인 토큰은 메모리 또는 운영체제의 보안 저장소에서 관리합니다. WebDAV 계정 인증 정보도 보안 저장소를 사용합니다. 로그인 토큰·비밀번호·기기별 온라인 번역 전송 동의·광고 제거 구매 권한은 책 설정 백업·동기화에 포함하지 않습니다. 일부 앱 설정과 인증·구매 캐시는 Android 자동 백업·기기 이전에서 제외합니다.

Google·Microsoft·번역·광고 서비스와의 통신에는 HTTPS를 사용합니다. 사용자가 지정한 일반 HTTP WebDAV·기기 연결은 암호화되지 않습니다. 이러한 연결에는 공용 Wi-Fi 대신 신뢰할 수 있는 네트워크, 동일한 Tailscale 네트워크 또는 HTTPS를 사용하세요. 모든 전송 경로가 암호화된다고 보장하지는 않습니다.

4. 광고 버전의 광고와 결제

광고 버전은 Google AdMob 및 UMP 동의 관리 SDK를 사용하여 서재 하단에 배너를 표시합니다. 독서 화면에는 광고를 표시하지 않습니다. 무광고 빌드는 이 광고·동의 관리·광고 제거 결제 SDK를 포함하지 않습니다. 공식 테스트 광고 버전에는 광고 수익과 실제 결제가 없습니다.

Google 광고 SDK는 광고 제공·측정·분석·부정 이용 방지를 위해 IP 주소와 그로부터 추정한 대략적인 위치, Android 광고 ID·앱 세트 ID 등 기기/계정 식별자, 앱·광고 상호작용, 성능·오류·진단 정보를 자동 수집·공유할 수 있습니다. 광고 요청 매개변수에 책 원문·페이지 이미지·책장 목록을 넣지 않습니다. 자세한 범위는 Google Mobile Ads 데이터 안내와 Google 개인정보처리방침을 참조하세요.

필요한 지역·조건에서는 광고 동의 화면을 표시하며, 개인정보 선택 화면이 요구되는 경우 앱 설정의 ‘광고 개인정보 설정’에서 선택을 변경할 수 있습니다. 광고 ID 관련 선택은 Android 설정에서도 관리할 수 있습니다. 실제 광고 제공과 데이터 처리는 동의 상태·지역·운영체제 및 제공자 설정에 따라 달라집니다.

광고 제거 결제가 제공되는 버전은 Google Play를 통한 일회성 비소모성 구매를 사용합니다. 개발자가 카드 정보를 직접 입력받지 않습니다. 앱은 상품·구매 상태, 구매 토큰이 포함된 서명된 구매 내역과 서명을 기기에 보관해 권한을 확인합니다. 구매 복원은 동일한 Google Play 계정을 사용합니다. 구매 상태·환불은 온라인 구매 조회 후 반영될 수 있으며, 오프라인에는 마지막으로 검증한 내역을 사용합니다. 구매 내역은 책 백업·동기화와 Android 자동 백업에서 제외합니다.

5. 보관·삭제와 사용자의 선택

  • 기기에 저장한 책장·설정 정보는 앱을 사용하는 동안 유지됩니다. 책장 등록 삭제는 책장 정보만 제거하며 원본 파일을 삭제하지 않습니다. 앱 데이터 삭제·앱 제거 전에 필요한 설정을 백업하세요.
  • 원본 파일, 변환·내보낸 파일, 백업과 클라우드 데이터는 각각 저장한 위치에서 별도로 삭제할 수 있습니다. 로그인 정보 초기화는 이 기기의 연결을 해제하지만 이미 클라우드에 저장한 백업까지 지우지 않습니다. Google·Microsoft 계정에서도 앱 접근 권한을 철회할 수 있습니다.
  • 로그인 토큰·저장한 연결 인증 정보는 앱의 로그인 정보 초기화 또는 앱 데이터 삭제로 제거할 수 있습니다. 원본 파일과 외부에 내보낸 파일은 별도로 관리하세요.
  • 외부 제공자가 수신한 정보의 보관 기간·삭제 방법은 해당 제공자 정책과 계정 기능을 따릅니다. 제공자에게 이미 전달된 정보를 앱이 직접 모두 삭제할 수 있는 것은 아닙니다.
  • 번역 진단에는 원문·번역문이 포함될 수 있습니다. 문의를 위해 복사·공유할 때 민감한 내용과 공유 권한을 확인하세요. 문의 이메일로 받은 정보는 문의 응대에 사용하며 처리가 끝나 불필요해지면 삭제합니다. 관련 법령상 보관이 필요한 경우에는 그 범위에서 보관합니다.
