책·만화·글꼴의 권리

앱의 구매·설치는 책·만화·글꼴의 이용 권한을 포함하지 않습니다. 이용 권한이 있는 파일만 추가하고 변환·공유해 주세요. 앱은 책 콘텐츠나 DRM 해제 기능을 제공하지 않습니다.

새 출시 준비판의 번역

지원되는 Android 기기에서 Google Translate 기반 ML Kit 온디바이스 번역을 사용합니다. 모델 다운로드와 SDK 진단 통신은 발생할 수 있으나 책 원문·번역문·페이지 이미지를 번역 서버로 전송하지 않습니다. 온라인 번역은 정식 API 연결 전까지 제공하지 않습니다. 기능의 적용 시점은 설치한 버전에 따라 다릅니다. Google Translate / Cloud Translation · ML Kit 번역 이용 안내

오픈소스 구성요소

앱 정보의 ‘오픈소스 라이선스’에서 각 구성요소의 저작권·라이선스와 하위 라이브러리 고지를 확인할 수 있습니다. 새 출시 준비판의 PDF 기능은 MIT 라이선스의 pdfrx와 별도 고지를 포함한 PDFium을 사용하며 Syncfusion을 포함하지 않습니다. OCR 모델, EPUB 엔진, 압축 처리 라이브러리 등에는 각자의 라이선스가 적용됩니다.

새 출시 준비판의 SMB 라이브러리와 LGPL 권리

libsmb2는 LGPL-2.1-or-later이며 유료 앱 판매와 관계없이 라이선스의 권리가 유지됩니다. 해당 버전 소스·빌드 스크립트·패치는 앱에 함께 들어 있습니다. 앱 정보 → 라이선스 및 이용 안내 → ‘SMB 라이브러리 소스 저장’으로 원본 소스 묶음을 저장할 수 있습니다. 수정·교체 방법은 묶음의 README.txt에 있습니다. 라이브러리 수정과 그 수정의 디버깅에 필요한 역공학은 LGPL에서 허용하는 범위에서 허용되며 앱 이용 조건으로 제한하지 않습니다. 바이너리 릴리스와 라이선스 · 해당 빌드 스크립트·패치 · 해당 원본 소스

상호와 제품명은 각 권리자의 표장입니다. 구성요소 사용은 해당 권리자의 앱 보증이나 제휴를 의미하지 않습니다.
