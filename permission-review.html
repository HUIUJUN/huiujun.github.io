PageRoom: permission review

Actual Android 15 app recordings, version 1.0.0 (117), captured 30 October 2026. These are permission review demonstrations, not simulated marketing screens. Idle intervals are trimmed; screen transitions are not generated or interpolated. Only original demonstration documents are shown.

Local document management / all files access

The Android all-files setting was already enabled. The folder-picker confirmation is a separate Storage Access Framework (SAF) prompt. The recording then shows folder import, the imported PDF's original storage location and reading the document. It does not claim that SAF cannot support folders.

User-initiated EPUB export / foreground task

The user starts an export, selects its destination and leaves the app. The Android foreground notification reports EPUB conversion in progress. The task queue subsequently confirms the exported filename. An unrelated earlier sync timeout notification is visible beside the export notification; it is not presented as successful cloud backup.

Google Drive backup / synchronization

After the user signed in separately, the user starts a real Drive synchronization, leaves the app and views its foreground progress notification. Android subsequently reports completion with no changes. This is not a waiting receiver or simulated backend. Unrelated account notifications are covered by a solid mask before publication; no credentials or contact details are shown.

User-initiated crop / local processing

The user opens settings for a twelve-page original sample comic and saves a crop job. The app leaves the foreground and Android shows the task status. This small job finishes quickly; the closing frame is an explicitly labelled actual screenshot of the completed task queue. The original archive is preserved.
